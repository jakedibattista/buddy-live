## Completed 2026-05-25 (was “open items for tomorrow”)

### A. peek_camera blind spot — **DONE** (`e08cf9b`, `ee8e1b1`)
- Root cause: vision model conflated “no stick / upper body only” with invisible; not a pipeline failure.
- Fix: structured PERSON/STICK/SETUP/COACH prompt; `person_visible`, `full_body_in_frame`, `facing_camera`, `setup_framing_passed`; never say “I don’t see you” when `person_visible=true`; amber camera-hint banner after 2 failed peeks; peek uploads start when session + camera exist.

### B. Conversation design — **DONE** (`db98331`, `ee8e1b1`, prompt polish ongoing)
- Hockey tangents: one sentence + redirect (IQ questions are **in-flow** during analysis wait, not tangents).
- Visibility: no “let’s go anyway” while framing fails; UI banner + `camera_hint` on session doc.
- Graceful end: red phone button → wrap-up message → ~12s → disconnect; `end_session_recap` gated on ready scorecard.
- UI: system transcript timeline, activity indicator, next-turn cues, phase label, quick prompts (`I'm ready`, `Wrap up`), talking puck mascot.

### C. Recording flow — **DONE** (`6210065`, `ee8e1b1`; E2E verified in live session)
- `stop_rep_capture` → client stops + uploads; 60s REC countdown + **Stop & upload**; `/api/reps/analyze` idempotent kickoff; `analyze_rep` polls for clip; `useRepResultsPolling` refreshes jobs; scorecards in side panel; `results_ready_at` on session when first rep completes.
