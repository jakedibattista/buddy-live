## What landed 2026-05-27 (pm)

### J. Agent runaway fix + session resilience — **DONE**

Root cause from a live session (`live-pgi5ponazebf`): during the second warm-up action (arm circles retry), the agent entered a degenerate tool-calling loop that ran for 301 seconds, produced a 504KB SSE response, and was killed by Cloud Run's timeout. Contributing factors: stale peek frames, "..." silence fillers polluting the conversation, overlapping concurrent turns from ElevenLabs, and no guard on the ADK runner's LLM call count (default was 500).

| Area | What shipped |
|------|----------------|
| **max_llm_calls cap** | `RunConfig(max_llm_calls=10)` — caps tool-calling rounds per user turn. Normal ops use 2–5; prevents runaway loops. |
| **Silence filter** | `"..."`, `""`, `"."`, `".."`, `"…"` from ElevenLabs silence detection are returned as empty SSE immediately — no Gemini call, no session history pollution. |
| **Per-session lock** | `asyncio.Lock` per session_id serializes concurrent turns. Two utterances arriving 200ms apart no longer corrupt InMemorySessionService state. |
| **30s turn timeout** | `asyncio.timeout(30)` around `run_async`. If a turn hangs, bails with "Hold on one sec — let me catch up." instead of burning 5 minutes. |
| **Clear peek_url_history on timer start** | `start_warmup_timer` resets `peek_url_history: []` so `peek_warmup` only analyzes frames captured during the exercise, not stale pre-timer frames. |
| **Flexible rep count** | Prompt now asks how many pucks/balls the player has. Supports 1-puck workflows (shoot → pick up → shoot again). Player can bail after any rep with results. |

**Files:** `app/main.py`, `app/tools/warmup_timer.py`, `app/prompts.py`

### K. IQ Mode polish + Reconnect race fix + Client-side connection saturation fix — **DONE** (`8f652ea`, `726f374`, `f72bc12`)

Root causes from live tests (`live-100087zdo0yq`, `live-2zzlfdgpnumi`, `live-ir01l86875m0`): (a) prompt asked for drill before checking space/equipment; (b) visual scenario cards popped up before questions were asked; (c) visuals were constrained to a tiny sidebar; (d) right/wrong options lacked feedback; (e) language was too complex; (f) voice shifted entering IQ mode; (g) reconnection had a race condition causing infinite loops; (h) uploader flooded connections, causing WebRTC drops; (i) cards showed stale hardcoded '5 reps' text.

| Area | What shipped |
|------|--------------|
| **Reordered opening** | Space, stick, and puck check now comes **before** drill selection. If the player lacks space, they hand off to the IQ sub-agent immediately without locking or showing shooting drills. |
| **Big IQ overlay** | During `currentPhase === "iq_practice"`, we completely hide the camera and place a beautiful, full-size overlay card with a much larger half-rink visual diagram. All camera, framing, and timer overlays are hidden to prevent clutter. |
| **Visual timing** | Prompts are hard-gated to say the scenario out loud first, then call `show_iq_visual` at the very end of the turn so the card lands as reference instead of pre-empting speech. |
| **Answer marking** | New tool `mark_iq_answer(player_choice, correct_choice)` writes to Firestore. The card animates correct choices in green with a ✓, and wrong choices in red with a ✕. Auto-clears when the next scenario fires. |
| **Child friendly prompt** | Explicit child-friendly (ages 10–11) vocabulary level. No un-explained jargon (five-hole, slot, etc.). Includes a dynamic "Rules Mode" with rules-only scenarios if they say they want to learn the rules of the game. |
| **Voice continuity** | `IQ_COACH_PROMPT` now mirrors the main coach's style and personality blocks and forces contractions ("let's", "you're") so the voice is 1:1 identical across handoffs. |
| **Reconnect race fix** | Eliminated client-side race condition in `CoachConversation.tsx` where resume messages were sent on a raw 900ms timer immediately after `startSession()`. Resume triggers are now queued and sent safely 500ms after ElevenLabs invokes `onConnect()`. |
| **Socket saturation** | Introduced an `inFlightRef` guard in `usePeekFrameUploader.ts` to prevent parallel uploads. Chrome's 6-connection limit was previously saturated with slow base64 uploads, blocking WebRTC websocket pings and Firestore snapshot listeners. |
| **Dynamic card phases** | Cleaned up the distracting hardcoded "5 reps" overlay. The DrillChip top-bar now dynamically updates to show exactly what phase the user is in: "Warm-up", "[Drill] practice" (e.g. Slapshot practice), "Cooldown & review", or "Hockey IQ". |
